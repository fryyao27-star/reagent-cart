# 3D 赛车

一个无需构建工具即可运行的 Three.js 3D 赛车小游戏。

## 操作
- PC：WASD 或方向键
- 手机：屏幕下方触控按钮
- 点击“开始比赛”后完成 3 圈

## 技术
- HTML / CSS / JavaScript
- Three.js 0.179.1（ES Module CDN）
- 环形 3D 赛道、玩家赛车、3 个 AI 对手
- 响应式布局

## 运行
直接打开 `index.html` 即可。由于使用 CDN 加载 Three.js，首次运行需要网络连接。

## GitHub Pages
进入仓库 Settings → Pages，选择 main 分支即可部署项目目录；也可以将 `3d-racing/` 复制为独立站点根目录。
